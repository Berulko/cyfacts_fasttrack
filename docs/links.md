# Полезные ссылки

> Список ведётся вручную · ссылки проверены 09.10.2026

## Официальные

### Подача

- [Форма M127 и требования (МВД)](https://www.gov.cy/moi/en/documents/acquisition-of-cypriot-citizenship-by-naturalization-due-to-years-of-residence-form-m127/) — Официальная страница МВД: условия, форма заявления и порядок оплаты.
- [Перечень подтверждающих документов M127](https://www.gov.cy/moi/documents/apoktisi-kypriakis-ypikootitas-me-politografisi-logo-eton-diamonis-aitisi-m127/) — Живая страница МВД со списком документов к заявлению; она заменяет отдельные PDF.
- [Где подают заявления на гражданство](https://www.gov.cy/moi/en/documents/application-submission-offices/cypriot-citizenship/) — Официальный список офисов, куда подают заявления на гражданство.
- [Запись на подачу: Лимассол](https://limassoldistrictadmin.simplybook.it/v2/) — Онлайн-запись на приём в окружной администрации Лимассола.
- [Запись на подачу: Никосия](https://nicosiadistrictadministration.simplybook.it/v2/) — Онлайн-запись на приём в окружной администрации Никосии.
- [Запись на подачу: Ларнака](https://larnacadistrictadministration.simplybook.it/v2/) — Онлайн-запись на приём в окружной администрации Ларнаки.

### Документы

- [Справка о несудимости (полиция Кипра)](https://www.gov.cy/service/ekdosi-poinikon-pistopoiitikon-cro/) — Страница услуги о выдаче справки о несудимости (на греческом).
- [Реестр присяжных переводчиков](https://www.gov.cy/pio/en/sworn-translator/) — Официальный реестр переводчиков, чьи переводы принимают государственные органы.
- [Двусторонние договоры Кипра (перечень)](https://www.gov.cy/media/sites/18/2024/04/Bilateral-Agreements-30-11-23.pdf) — Перечень международных договоров Кипра, в том числе о признании документов без апостиля.
- [Мухтары (κοινοτάρχες) по округам](https://www.gov.cy/moi-elections/documents/koinotarches-enorion-dimarchoymenon-periochon/) — Официальный список мухтаров общин по районам.
- [Транслитерация греческого имени (ELOT 743)](https://www.passport.gov.gr/passports/GrElotConverter/GrElotConverterEn.html) — Конвертер греческого написания в латиницу по стандарту ELOT 743, который использует греческое МВД.
- [Регистрация ребёнка гражданина: форма M126](https://www.gov.cy/moi/en/documents/registration-of-a-minor-child-of-a-cypriot-citizen-as-a-citizen-of-the-republic-of-cyprus-form-m126/) — Официальная страница МВД с формой регистрации несовершеннолетнего ребёнка гражданина Кипра.

### Экзамены

- [Экзамены Министерства образования](https://www.moec.gov.cy/ypexams/en/examinations.html) — Официальная страница экзаменов, в том числе по греческому языку.
- [Экзамен по основам политической и общественной реальности](https://www.moec.gov.cy/ypexams/exams/pistopoiisi_eparkous_gnosis_vasikon_stoicheion_pragmatikotitas_kyprou.html) — Страница Министерства образования об экзамене на знание основ политической и общественной реальности Кипра.

### Законы

- [Закон о гражданстве 141(I)/2002](https://www.cylaw.org/nomoi/enop/non-ind/2002_1_141/full.html) — Полный текст закона на правовом портале Кипра.
- [Поправка 149(I)/2023 (статья 111B)](https://www.cylaw.org/nomoi/arith/2023_1_149.pdf) — Текст поправки со статьёй 111B о высококвалифицированных сотрудниках.

## Неофициальные

> Сделаны сторонними авторами; мы их не проверяли. Где база знает о неточностях — сказано в строке.

- [Гайд по фаст-треку (сайт на Tilda)](https://cypassport.tilda.ws/) — Неофициальный подробный гайд по этапам подачи. Больше не обновляется, часть ссылок на нём не работает; в отсчёте срока проживания расходится с практикой.
- [Калькулятор дней отсутствия (Tilda)](https://cypassport.tilda.ws/days) — Неофициальный калькулятор с тремя вариантами подсчёта превышения 90 дней; для одного варианта источник не указан. Сверяйте с законом.
- [Калькулятор дней проживания](https://treboit.github.io/cyprus-residence/) — Неофициальный инструмент подсчёта дней и приложений к форме M127. Считает по мягкой трактовке правила и содержит неточности (високосный год, дата ARC). Данные хранятся в браузере.
- [Гайд по фаст-треку (Notion)](https://lumpy-decision-132.notion.site/Fast-track-cf3576c436f34dc881da241143f4b929) — Неофициальный короткий гайд, дополняет официальный список документов МВД.
- [Статья о получении гражданства по фаст-треку](https://cy.solt.media/citizenship/cyprus-fast-track-citizenship/) — Статья с личным опытом получения гражданства, включая пример сопроводительного письма к портфолио интеграции.
